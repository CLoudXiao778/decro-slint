# Decro Slint

Decro 的 Slint 原生 UI 便携版。界面按既有 Tauri 版重绘：自定义标题栏、图标侧栏、大卡片首页、悬浮播放 dock，以及带封面氛围背景的播放页/歌词页。不依赖 WebView2。

## 当前功能

- 网易云扫码登录 / 网页 Cookie 导入 / 登录状态恢复，凭证使用 Windows DPAPI 加密
- 默认使用 OpenGL（femtovg）硬件渲染，无可用 OpenGL 环境时自动回退软件渲染
- 按 Tauri 版重绘的应用外壳：自定义标题栏、窗口按钮、图标侧栏、可点击页面头像
- 浅色/深色主题：标题栏日月切换或设置页开关，主题持久化；播放页/歌词页/队列按设计保持深色
- 首页：每日推荐 / 推荐歌单大卡片，推荐歌单、新歌速递、最近播放横向封面架
- 最近播放：合并网易云历史与本地播放记录，支持“查看全部”整页滚动列表
- 资料库：登录卡片、我的歌单（置顶/使用频率排序、常用 8 个/展开全部）、最近播放
- 搜索：大号圆角搜索框（可点击“搜索”或回车），支持歌曲/歌单/歌手/专辑/歌词分类；区分“输入中/已提交/正在搜索”，整页单一滚动
- 歌单详情：封面氛围 hero、居中大播放按钮、随机播放、分享/更多、曲目菜单（播放/喜欢/复制信息）、收藏/取消收藏；整页单一滚动，不再嵌套列表
- 歌手/专辑页：热门歌曲、歌手专辑架、专辑歌曲列表，支持逐级返回
- 播放 dock：Tauri 同款悬浮胶囊，封面/歌曲信息/播放/下一首/底部进度线
- 播放页：封面高斯模糊背景、大封面、标题/歌手/专辑、喜欢、更多菜单（查看歌手/专辑、复制歌曲信息、单曲音质覆盖）、波形进度条、传输控制、播放队列面板；专辑/多歌手名可分别点击并跳转详情，悬停显示下划线；打开/返回时封面与播放/下一首按钮从 dock 飞行并变形，点击封面或“打开歌词”进入歌词模式
- 播放页/歌曲详情页开关、页面切换带淡入淡出动画
- 歌词：大字号、当前行高亮、自动居中跟随；支持滚轮/拖动查看、点击歌词跳转，手动滚动后暂停跟随并可“回到当前”；歌词搜索分类可跳转播放
- 真实歌单/歌曲封面，按显示尺寸加载（架子 256px、大卡片/播放页 500px），打开页面时预取前若干张并在后台线程解码，缓存到 `data/covers/`（启动时最多保留 3000 个文件）
- 设置：账号、深色模式、音质（自动/标准/较高/极高/无损/Hi-Res，切换立即重载当前曲）、日志级别（debug/info/warn/error/none）、封面氛围背景、歌词翻译、性能模式、数据目录
- 资料库支持新建歌单、通过歌单 ID/链接添加歌单
- 上次播放队列/曲目/进度恢复（最多 500 首上下文，5 秒周期保存，原子写入），音量持久化
- Windows 系统媒体控件（SMTC）：媒体键、系统媒体浮层、任务栏封面/播放状态与播放进度/时长，支持系统浮层拖动进度（seek）
- 任务栏缩略图：上一首/播放暂停/下一首按钮，任务栏播放进度（播放/暂停/停止状态）
- 内存诊断日志与最小化工作集回收（startup / periodic / minimize / restored）；最小化时跳过非必要 UI 更新
- 登出会停止播放、清空队列/当前曲/歌词/系统媒体浮层和上次播放文件
- 全部数据位于 exe 同目录 `data/`，便携升级只覆盖 exe

## data 目录

| 文件/目录 | 内容 |
| --- | --- |
| `netease-auth.bin` | DPAPI 加密的登录凭证 |
| `settings.json` | 音量、音质、主题、封面氛围、歌词翻译、性能模式 |
| `last-playback.json` | 上次播放队列、索引和播放进度 |
| `recent-played.json` | 本地最近播放历史（最多 200 首，和网易云历史合并） |
| `playlist-state.json` | 歌单置顶 ID 与打开次数（资料库排序） |
| `track-quality.json` | 单曲音质覆盖（按歌曲 ID） |
| `log-level` | 日志级别 |
| `logs/decro.log` | 运行日志 |
| `covers/` | 封面缓存（启动时最多保留 3000 个文件） |
| `audio-cache/` | 当前播放曲目的临时音频文件，启动时清理 |

## 构建与发布

正式构建和发布只通过 GitHub Actions 完成，不在本地构建或手动上传 Release。

1. 更新 `Cargo.toml` 版本、`ui/app.slint` 设置页 footer 和 `CHANGELOG.md`，提交并推送 `main`。
   - push `main` 会自动运行 `cargo fmt --check`、`cargo test`、release 构建并上传 Actions artifact，但不会发布。
2. 推送与版本一致的 tag，例如 `v0.4.5-slint`：
   ```bash
   git tag v0.4.5-slint
   git push origin v0.4.5-slint
   ```
3. Actions 会再次运行格式检查、测试和 release 构建；校验 tag 与 `Cargo.toml` 版本一致后，自动发布 GitHub prerelease，并附带 zip 与 SHA256。
4. Windows 构建静态链接 CRT，不需要安装 VC++ 运行库；不要在本地执行 release 构建或 `gh release create`。
5. Git 凭据使用 OpenChamber 的 `git-credential-openchamber`（GitHub OAuth），不再使用独立安装的 `gh` CLI；GitHub 操作优先使用 OpenChamber 的 GitHub 集成。

## 已知限制

- 测试版，原生 UI 重绘，不是 Tauri 版的逐像素复刻
- 没有 WebView 式的实时 backdrop blur；播放页/详情页背景使用 `image` crate 对封面做真实高斯模糊（算法模糊），不是实时模糊整个 UI
- 暂无桌面歌词、托盘、命令面板、应用级快捷键、全局快捷键
- 浅色主题只覆盖应用外壳；播放页/歌词页/队列按沉浸式设计保持深色
- Windows 11 若系统不再显示传统任务栏缩略图工具栏，则缩略图按钮不可见（进度条仍可用）
- 资料库/最近播放/详情/搜索的歌曲列表尚未全量虚拟化（队列已使用 `ListView`，封面预取已限量、解码已移到后台线程）
- Cookie jar 与服务端 Set-Cookie 续期尚未全量同步到所有直连请求
- exe 未签名，Windows SmartScreen 可能提示
